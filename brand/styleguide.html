c is for…

coffee

The open c is the rim of a cup; the dots rise like steam.

chat

The same dots, read across: someone is typing.

<c/>

code

Set in a monospace, with a cursor, because it lives in a terminal.

claude

An unfinished circle is a spinner: Claude is working, so you're on a break.
