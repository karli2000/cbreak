cbreak GitHub

a coffee break while Claude works

cbreak is a Claude Code plugin. While Claude is busy on your task, a small chat room opens next to your session, full of other people who are waiting on Claude too. When Claude is done, the room closes and you are back at work.

Install cbreak Read the source on GitHub

How a break goes

  1. Claude gets busy

    After 15 seconds of work, the room opens beside your session. In a narrow terminal you get a hint instead, and /cbreak opens it.

  2. You chat

    Everyone in the room is waiting on Claude too. Messages disappear after 15 minutes, and for the rest of your session your breaks take you back to the same people.

  3. Claude is done

    A 15 second countdown starts, then the room closes. A half-typed message keeps it open until you send or clear it.

Install

You need Claude Code 2.1.322 or newer and Bun 1.2 or newer. No Bun yet?

curl -fsSL https://bun.sh/install | bash

Then add the plugin from its GitHub marketplace:

claude plugin marketplace add karli2000/cbreak
claude plugin install cbreak@cbreak

Restart Claude Code and run /cbreak setup: sign in with GitHub, pick a nickname and accept the room rules. That's it. The next time Claude works for a while, the room opens.

What leaves your machine

cbreak sees your prompts and tool calls, because it has to know when Claude is busy, but it never sends them anywhere. Only four things leave your machine: your sign-in token, the room name, what you type in the chat and reports you file.

Messages are deleted after 15 minutes. /cbreak delete-account yes deletes your account. The backend runs on Supabase in Frankfurt.

Who is in the room

Anyone with a GitHub account can join; other people only see your nickname. The rules are short: be kind, no spam, don't share private or company data.

Moderators can delete messages, mute and ban. Anyone can report a person with /report, and three reports in 10 minutes mute them for a day.
